# צילומי מסך לדף הנחיתה

כאן שומרים את צילומי המסך האמיתיים של האפליקציה, כדי שקלוד ישתיל אותם בדף הנחיתה.

## איך עושים את זה
1. שומרים כל צילום מסך לתיקייה הזו (`src/assets/screenshots/`).
2. נותנים שמות פשוטים באנגלית, למשל:
   - `home.png` — מסך הבית (יתרת הקופה, קטגוריות)
   - `students.png` — רשימת התלמידים
   - `gifts.png` — מתנות/ספקים
   - `calendar.png` — לוח שנה
3. כותבים לקלוד: "העליתי צילומי מסך" — והוא מחליף את המוקאפים בצילומים האמיתיים
   בכל סקשן מתאים.

הערה: עדיף צילומי מסך של נייד (פורטרט), חדים. קלוד ימקם אותם בתוך מסגרת טלפון.
